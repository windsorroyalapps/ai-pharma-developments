Automation & Agent Features

Backend automation for orders, payments, and fulfillment. Agent-gated with confirm=true. Integrates with Stripe, Cloud Run, Secret Manager, and Pub/Sub.

Payment Automation

  • Stripe Checkout Session creation via Cloud Run worker
  • Webhook handling for checkout.session.completed
  • Append-only ledger (JSONL / Firestore)
  • Google Pay via Stripe gateway
  • Agent orders require explicit confirm=true

See pay.html for frontend. Secrets in Secret Manager only.

GCP & WIF

  • Least-privilege SAs: apd-payment-sa, apd-deploy-sa
  • Workload Identity Federation for GitHub Actions (no keys)
  • Region: australia-southeast1
  • Bootstrap via cloud/iam/bootstrap.sh after gcloud auth

Operator must authenticate gcloud and set project before IAM changes.

Future Automation

On payment success: create Stripe Customer, trigger Pub/Sub for fulfillment agent, optional email receipts. Subscriptions and multi-currency planned.

Local dry-run server available in cloud/worker/dry-run-server.js for testing without live keys.
